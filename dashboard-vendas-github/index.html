Escopo e qualidade da análise

Fonte Base fornecida: código da venda, data, valor e vendedor, com o cadastro de 10 vendedores. A análise mede faturamento, volume, ticket, sazonalidade e performance comercial. A base não possui cliente, produto, quantidade, custos, metas ou margem; por isso não é possível avaliar rentabilidade, conversão, mix ou atingimento de meta. Valores são tratados como receita bruta registrada.
